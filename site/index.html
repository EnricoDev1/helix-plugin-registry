An unofficial community directory for the experimental Steel plugin system.

Setup

# Build Helix with Steel
          git clone https://github.com/mattwparas/helix.git
          cd helix
          git switch steel-event-system
          cargo xtask steel


          # Install and load a plugin
          forge pkg install --git https://github.com/<author>/<plugin>.git
          (require "<plugin>/<plugin>.scm")

Run locally. Check the branch instructions and each plugin repository first.

About this directory

Helix Plugins is an independent community index. Listings point to public repositories with documentation, but inclusion is not a security review, compatibility guarantee, or endorsement by the Helix or Steel projects.

The plugins target ongoing Steel integration work and may require the steel-event-system branch or another compatible Helix build. Review each repository before installing. Directory content was last reviewed in August 2026.
