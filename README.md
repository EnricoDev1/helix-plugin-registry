# Helix Plugins

An unofficial, community-maintained index for plugins built against Helix's experimental Steel plugin system.

The website helps people find plugins and understand the setup path.

## Submit a plugin

Open a [plugin submission issue](https://github.com/EnricoDev1/helix-plugin-registry/issues/new?template=plugin-submission.yml) when your repository is ready for review.

Before submitting a plugin:
- Host the plugin in a public repository;
- Include a README with installation and loading instructions;
- Include a license file and name any external dependencies;

Next, a maintainer will review the issue for completeness and, if everything checks out, add the plugin to the listing.

## Security

Listings are not security-reviewed or endorsed. See the [security policy](SECURITY.md) to report a concern privately.

## Disclaimer

- This project is independent and is not affiliated with, sponsored by, or endorsed by the Helix project or Steel.
- Do not describe a plugin as verified, safe, official, or compatible with Helix main unless a source supports that claim.

## Conduct

Be constructive and respect plugin authors, reviewers, and users. Discuss technical concerns with evidence and avoid publishing security-sensitive details in a public issue.
