# Security policy

Please notice that being listed here doesn't mean a plugin has been reviewed or approved — install at your own discretion.

For a security concern about this website or a listed plugin, do not publish exploit details in an issue.
Use [GitHub's private vulnerability reporting](https://github.com/EnricoDev1/helix-plugins/security/advisories/new) for this repository and include the affected URL or plugin, impact, and a way to reproduce the problem.
